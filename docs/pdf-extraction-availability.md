# PDF 추출 결과의 가용성과 품질

읽어낸 텍스트는 페이지·레이아웃 검증이 불완전해도 반환하고 신규 수집 문서에 저장한다. `success`는 사용 가능한 텍스트의 존재를 뜻하며, `extraction_status`와 `paragraph_projection.status`는 품질 상태를 별도로 전달한다. 오류 메시지와 빈 문자열은 원문으로 저장하지 않는다.

검증된 문단·표 구조는 그대로 사용한다. 검증되지 않은 구조는 읽힌 원시 텍스트를 평문으로 표시하고 `needs_review`와 실패 쪽 정보를 유지한다. 여러 첨부 중 일부가 실패해도 성공한 첨부의 텍스트를 버리지 않으며 `[첨부파일 추출 본문 · 일부 미확인]`으로 표시한다. 짧은 본문도 글자 수 기준으로 버리지 않는다.

기존 문서의 불완전한 재수집은 기존 본문·해시·벡터를 보존하고 재시도 진단을 남긴다. 이는 결과 텍스트를 반환하는 API 계약과 별도인 기존 DB 교체 정책이다. 원문 재검증을 통과한 복구 후보는 검증된 마이그레이션 경로로 반영한다.
